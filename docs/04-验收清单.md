# 比赛前验收清单

> **已实测通过（2026-11-01，真机 WCU_MY32_CD35 + 奇艺 Smart Player Pro）**
> A 段（自检）、C 段（连 App）、D 段慢速跟随、**E 段连做 3 把无 DNF、秒数正确**。
> 下面清单里 ✅ 标记的是已验证过的；其余仍需现场补测。

> 用法：从上往下逐项过，**打勾才算过**。任何一项不过，都不要拿去比赛。
> 建议两人配合：一人转魔方，一人盯串口日志（`idf.py monitor` 或任意串口助手）。

---

## A. 开箱（不需要手机）

- [ ] 上电后串口打印 `固件: qybridge 1.0.0`
- [ ] 打印 `===== 自检全部通过 =====`（任何 FAIL 都要先解决）
- [ ] 打印 `虚拟奇艺魔方 QY-QYSC-S-XXXX 地址 CC:A3:00:00:XX:YY`，
      且**名称后缀与地址后四字节一致**
- [ ] 打印 `广播中: QY-QYSC-S-XXXX`

## B. 连实体魔方

- [ ] 转一下魔方唤醒，放板子旁边
- [ ] 日志出现 `发现 WCU_...`、`已连接实体魔方`
- [ ] 出现 `已订阅实体魔方通知`
- [ ] 出现 `采纳状态 (首次快照): ...`（54 个字母，中心块对应的面要对）
- [ ] 随手转 3 步，日志出现 3 行 `[mv n]`，**n 连续不跳号**

## C. 连 App

- [ ] App 能搜到 `QY-QYSC-S-XXXX`
- [ ] 能连接，日志出现 `App 已连接`、`MTU = 99`（或更大）、`App 已订阅 fff6`
- [ ] 出现 `已推送 CubeHello`（在订阅后 800ms 内）
- [ ] App 里显示的 3D 魔方与实体魔方**颜色一致**（面序/色码正确性）

## D. 跟随（最重要的一项）

- [ ] 慢慢转 10 步：App 每一步都跟得上，**不重复、不跳跃**
- [ ] 快速转 10 步（约 1 秒）：仍然不丢步
  - 日志里 `[mv n]` 连续；不出现 `丢步`、`发送队列溢出`
- [ ] 连续做一条公式（如 `R U R' U'` × 6）后回到复原态
  - 最后一步那行应带 **`=> ACK=1 (复原)`**
- [ ] **不要**出现 `虚晃一下又弹回`（即 App 转一下又自己弹回去）

## E. 打乱 → 复原 → 成绩（核心验收）

- [ ] 按 App 给的公式打乱，App 显示的魔方与实体一致
- [ ] 复原，完成瞬间 App 停表并给出秒数
- [ ] **不弹**"本次复原步骤不完整"
- [ ] CFOP 四段都有数据（不是全 0）
- [ ] 同一套流程**连续做 10 把**，10/10 都不弹 DNF

> 这一步过不了就别比赛。若偶发，保留那一把的**完整串口日志**（从打乱开始到结束），
> 用日志里的 `丢步` / `中层转` / `快照与本地不一致` 定位。

## F. 复原重置

- [ ] 在 App 里点"复原重置"：虚拟魔方复原
- [ ] 同时日志出现 `已向实体魔方下发 0xA2 重置`
- [ ] 实体魔方被转乱后点该按钮：实体魔方内核也回到复原态（再转一步，App 显示正确）
- [ ] 点完按钮后继续转，跟随仍然正确（没有卡在"未知"状态）

## G. 稳定性

- [ ] 断开重连 App 3 次，每次都能正常跟随
- [ ] 拔插开发板电源 3 次，每次都能自动连上实体魔方（不用按任何键）
- [ ] 静置 5 分钟后再转：仍能跟随（唤醒后不丢同步）
- [ ] 隔 2 米 / 隔一个人：不掉线（掉线看 `实体魔方断开 reason=...`）
- [ ] 连续通电 30 分钟，不重启、不卡死
- [ ] 用充电宝供电（不是 USB 直连电脑）跑一把完整流程

## H. 现场准备

- [ ] 手机侧蓝牙 + "附近设备/定位"权限已开
- [ ] 附近没有第二只奇艺/魔域魔方处于唤醒状态
- [ ] 充电宝不会"小电流自动关机"（已验证 30 分钟）
- [ ] 带一根**数据线**（不是纯充电线）
- [ ] 备用板子/备用 bin 已备好（`release/qybridge-esp32s3-merged.bin`）
- [ ] 知道怎么快速救场：App 点"复原重置" → 若仍不同步，串口 `resync`

## 出问题时的速查

| 日志 | 含义 | 处理 |
|---|---|---|
| `丢步: 计数跳变 ...` | 实体魔方 → 板子 丢了 BLE 通知 | 靠近一点；串口 `resync`；检查是否有别的 App 连着魔方 |
| `收到中层转 raw=12` | 魔方上报了 M/E/S | 该把重来，解法避免 M 层公式 |
| `快照与本地不一致(仅告警)` | 本地与魔方快照不同 | 只在出现"丢步"后出现属正常；单独出现多为快照过期 |
| `发送队列溢出` | 手机侧吞吐不足 | 重连 App；确认没开省电模式 |
| `MTU x < 99` | 手机没给足 MTU | 断开重连；必要时关掉手机"蓝牙音频"相关优化 |
| `App 断开 reason=0x213` | App 主动断开 | 多为握手没完成：确认订阅后 800ms 的那帧 Hello 发出去了 |
